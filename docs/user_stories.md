# ユーザーストーリー

1. 料理名・ジャンル・材料・手順・画像を入力して、個人用レシピを登録できる。
2. 何人前かを指定すると、材料の数値が自動で再計算される。
3. 「適量」「少々」など計算対象外の材料も、そのまま把握できる。
4. レシピごとに調理ログを残して、味の反省や改善点を記録できる。
5. 料理名やジャンルでレシピを検索・絞り込みできる。
6. リスト表示とギャラリー表示を切り替えて、見やすい形式で確認できる。
7. 作ったレシピを材料だけ、または手順込みでテキスト共有できる。
8. レシピをZipでエクスポートして、他の端末へ移行できる。
9. Zipをインポートして、同名レシピの取り込み方法を選択できる。
10. 基準人数やテーマなどの設定を変更できる。
